# DragonFruit (stickninja) 0.1.0

The Phase 0.1 filename feature was accepted on 2026-09-23.

## Output filenames

Sliced output now has an editable filename pattern with a live sample preview. The default is `{printer_name}_{timestamp}_{material_name}_{layer_height}mm`; `{layer_height_um}` is also available for patterns such as `{layer_height_um}um`. The pattern persists across desktop restarts. The native output extension is added automatically, and each job keeps one timestamp from slice start through saving. Invalid placeholders and unsafe template literals show errors; unsafe profile names are made safe with a warning.

## Verification and limits

Nine focused formatter tests, typecheck, focused lint, a complete Windows debug build, and an isolated native CTB export smoke test passed. The exported CTB file was confirmed on disk with the suggested filename, and the custom pattern persisted after restarting the desktop app. The Windows x64 optimized frontend, typecheck, native, and NSIS build passed. The final installer completed a silent installation; its installed executable matched the built executable apart from the expected Tauri NSIS marker. The installed app opened with a fresh profile, displayed the correct title and About version `0.1.0`, and showed **Download fork releases manually** in Settings with the fork release link. See the [Phase 0.1 acceptance record](../phase-1-acceptance.md) for exact feature evidence and the manual checklist.

The native smoke covered one small model and one Saturn 2 profile. CTB reader compatibility, other printer profiles, broader slicing workflows, and printer behavior were not tested. Full repository lint retains inherited errors.
