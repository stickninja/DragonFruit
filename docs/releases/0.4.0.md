# DragonFruit (stickninja) 0.4.0

Phase 0.4, covering resin quantity and cost conversions plus CTB layer motion and PWM overrides, was accepted by the user on 2026-09-28.

## Resin quantity and cost

Material/color profiles can enter bottle quantity in mL, g, or kg, with an optional uncured-liquid density in g/mL. A positive finite density converts weight to equivalent volume and supports print mass and cost estimates. Without a valid density, volume entry remains usable and the app does not invent a weight conversion. Existing volume-based profiles retain their quantity and cost behavior.

## CTB layer motion and PWM

Enabled CTB V4/V5 timing supports individual model layers and one-based inclusive ranges, including encrypted files. Simple and Two Stage modes can override lift and retract motion; each range field inherits independently from bottom/normal settings, and later matching ranges win per field. The startup dummy is excluded from model-layer numbering. Simple CTB has separate bottom and normal PWM controls. An optional range PWM can inherit, set 0–100%, or override an earlier range independently of motion and timing; explicit range 0% encodes byte 0. The dummy always encodes PWM byte 1. The file-backed inspector shows the encoded byte and percentage.

The LOD calculator uses effective motion, requires mixed-motion ranges to be split before applying one value, and keeps user-entered raw LOD and waits until an explicit Apply. Estimated time uses the resolved exported plan. Range motion no longer requires firmware identification or confirmation; eligibility uses the CTB format and Settings Mode. Legacy capability metadata remains stored for compatibility but does not gate the feature. Encoded file support does not establish how a physical printer will behave.

## Verification and limits

The [Phase 0.4 acceptance record](../phase-4-acceptance.md) lists completed automated checks, native UI exercises, and independent UVtools decoding, with earlier gated-workflow results identified separately. Under the final no-gate workflow, the optimized frontend and native Windows build, full TypeScript check, 21 focused frontend tests, scoped lint, and native fixture encoding/decoding passed. A native UI export without firmware metadata produced a 41-layer encrypted CTB V5 file. Independent decoding matched lift distance, lift speed, retract speed, and PWM on all 41 file layers; the encoded inspector agreed on the sampled layer.

Broader profile copy and import/export checks, the legacy default-0 PWM app-export path, the remaining interactive validation matrix, and physical printer behavior remain unverified. No model or firmware compatibility is inferred from the synthetic files.
