# DragonFruit (stickninja) 0.3.0

Phase 0.3, covering CTB timing, LOD calculation, startup dummy layers, and per-layer inspection, was accepted on 2026-09-26.

## CTB timing and layer inspection

Timing is opt-in for CTB V4/V5, including encrypted variants; when disabled, export retains the existing legacy behavior. CTB profiles support bottom and normal raw light-off delay and wait values, plus ordered per-layer overrides with per-field inheritance. The LOD calculator supports Simple, Two Stage, and All Fields modes and applies values only when requested. An optional startup dummy layer can be included in output. The inspector shows encoded exposure, timing, and motion alongside model-layer and file-layer numbering. Reslice Now clears the previous saved path so an unsaved preview cannot appear to be the earlier exported file.

## Verification and limits

Focused timing tests, broader frontend regressions, TypeScript checks, focused native tests, independent UVtools decoding of V4/V5 and encrypted fixtures, native UI checks, and multiple optimized Windows release builds passed. One unrelated Elegoo timing test in the full native engine suite failed; comparison against the baseline confirmed it is inherited.

A user reported that UVtools agreed with DragonFruit settings they tested and that manually setting LOD in a UVtools-modified file worked. The user also confirmed a DragonFruit LOD hardware check was working, then accepted Phase 0.3. The printer/model, firmware, and CTB version were not specified, so this does not establish broad printer compatibility or verify the full Saturn 2/Saturn 3 matrix.

The full Saturn 2/Saturn 3 manual matrix, timing-disabled native reslice, profile bundle round trips, remaining legacy-output comparisons, and broader physical printer checks remain pending. The successful user-reported LOD hardware check is limited to the unspecified tested setup.
