# DragonFruit (stickninja) 0.2.0

The Phase 0.2 material color and independent variants feature was accepted on 2026-09-24. The Windows package passed build and upgrade installation checks.

## Material colors and variants

Material profiles can include an optional color name and `#RRGGBB` swatch. The material list shows color metadata with the profile name; statistics and slicing use a composite material label that includes the color. The existing `{material_name}` filename placeholder therefore includes the selected material's color.

Create Color Variant opens a draft that copies the selected material's print settings into a new, independent profile. Creating the variant gives it its own identity and settings; cancelling the dialog creates nothing. Exposure, motion, anti-aliasing, local output settings, and other profile settings remain independent between variants. Material bundle names include a color suffix. Model tinting is deferred.

Legacy colorless profiles retain their existing appearance and behavior. Color metadata is optional in the existing profile storage schema, and profiles without it remain valid.

## Verification and limits

The focused material-color and filename tests passed 11/11, focused ESLint passed, and the optimized frontend, TypeScript, and isolated Windows release no-bundle native builds passed. A full-frontend browser run verified variant creation/cancellation, independent settings, and reload. The native picker accepted and exported an edited swatch.

The native output filename integration is covered by automated tests; no actual sliced-file export or hardware print was performed for Phase 0.2. Full repository lint retains inherited findings, with no added error or warning signatures in the reviewed files.
