# Phase 0.2 review screenshots

These screenshots show the Phase 0.2 material color and variant workflow in a Windows review build. The test materials are independent Grey and Black profiles. The user accepted the Phase 0.2 feature on 2026-09-24; release packaging is separate.

![Independent Grey and Black test profiles](images/phase-2/01-material-variants.png)

Independent Grey and Black test profiles, each with its own print settings.

![Optional color name and swatch in the Meta tab](images/phase-2/02-material-color.png)

Optional color name and swatch controls in the Meta tab.

![Create Color Variant dialog](images/phase-2/03-create-color-variant.png)

Create Color Variant copies print settings into a separate profile. Cancel closes the dialog without creating a profile.
